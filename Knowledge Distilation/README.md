# Knowledge Distillation

This directory is reserved for Knowledge Distillation (KD) study notes, implementations, experiments, and resources.

Knowledge distillation is a model compression and knowledge-transfer technique in which a student model learns from a teacher model, often using the teacher's softened output probabilities (logits) in addition to ground-truth labels.

## Planned contents

- Teacher–student architecture
- Soft targets and temperature scaling
- Distillation loss (KL divergence) and hard-label loss
- Training implementation and experiments
- Evaluation against the teacher and baseline student
