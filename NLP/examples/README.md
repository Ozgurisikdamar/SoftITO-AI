# NLP examples

Run the tokenizer without installing third-party packages:

```bash
python NLP/preprocessing.py
```

Run the illustrative TF-IDF classifier after installing dependencies:

```bash
python -m pip install -r requirements.txt
python NLP/tfidf_classifier.py
```

The embedded dataset is intentionally tiny and synthetic. Reported metrics are for demonstration only, not a reliable estimate of real-world performance.
