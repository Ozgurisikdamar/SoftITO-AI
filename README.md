# SoftITo-AI

İstanbul Ticaret Odası İleri Seviye Yapay Zekâ Mühendisliği eğitim çalışmaları ve uygulamalı kod örnekleri.

## Konu başlıkları

- [Big Data](Big%20Data/README.md) — Hadoop Streaming, MapReduce ve PySpark batch ETL
- [ETL-ELT](ETL-ELT/README.md) — veri entegrasyonu, kalite kontrolleri, Python ETL ve SQL ELT
- [NLP](NLP/README.md) — metin ön işleme, TF-IDF ve metin sınıflandırma
- [RNN](RNN/README.md) — tekrarlayan sinir ağları
- [LSTM](LSTM/README.md) — kapı mekanizmalı uzun kısa dönem hafıza
- [GRU](GRU/README.md) — gated recurrent unit

## Kullanım

Her konu klasörünün README dosyasında amaç, içerik, gereksinimler ve çalıştırma adımları bulunur. Kod örnekleri eğitim amaçlıdır; üretim kullanımından önce gerçek veri, güvenlik, test, izleme ve hata yönetimi ihtiyaçlarına göre uyarlanmalıdır.
