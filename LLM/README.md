# Large Language Models (LLM)

Learning materials, implementations, experiments, and projects related to Large Language Models.

## Topics

- LLM fundamentals and language modeling
- Tokenization and embeddings
- Transformer architecture
- Self-attention and causal attention
- Pretraining and next-token prediction
- Instruction tuning and alignment
- Fine-tuning (SFT, LoRA, QLoRA)
- Quantization and inference optimization
- Evaluation and benchmarking
- Prompt engineering
- LLM deployment and serving
- RAG and tool use

## Learning Path

1. NLP and language modeling fundamentals
2. Neural networks and sequence models
3. Transformer architecture
4. Tokenization and embeddings
5. Pretraining objectives
6. Instruction tuning and fine-tuning
7. Evaluation and inference optimization
8. Deployment and practical applications

> Note: RAG and Fine-Tuning have dedicated directories in this repository; this folder focuses on core LLM concepts and learning materials.
