# Python Temelleri ve Veri İşleme

Bu klasör, Python temellerinden Pandas ile tablo verisi okumaya ve işlemeye uzanan eğitim notlarını toplar.

## Notebook
- `python_pandas_basics.ipynb` — Python veri yapıları, Pandas Series/DataFrame ve CSV/Excel dosyalarıyla çalışma. Kaynak: `2-python  17.09.2026.ipynb`.

## Öğrenme hedefleri
- Series ve DataFrame oluşturmak
- CSV ve Excel dosyalarını içe aktarmak
- Veri tiplerini ve tablo boyutlarını incelemek
- Basit veri dönüştürme adımlarını uygulamak

Notebook içinde kaynakta belirtilen dosya yolları (`/content/grocery_chain_data.csv`, `/content/Superlig_Proje.xlsx`) örnek veri dosyaları gerektirir; bu dosyalar mevcut değilse ilgili hücreler çalıştırılmadan önce kendi dosya yolunuzla değiştirilmelidir.
