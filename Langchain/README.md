# LangChain ve LLM Application Engineering

Bu klasör, LangChain ile LLM uygulamaları geliştirmekten ajan iş akışları, ileri RAG, değerlendirme ve production operasyonlarına geçişi ele alır.

## Çalışmalar

| Dosya | İçerik |
|---|---|
| [LangChain — Detaylı Rehber](langchain-rehberi.html) | LangChain'in amacı, model entegrasyonları, LCEL, tools/agents, memory, LangGraph ve MCP ilişkisi; minimal ajan örneği. |
| [LangChain Sonrası Yol Haritası](langchain-sonrasi.html) | LangGraph state/edges/loops, persistence, human-in-the-loop, multi-agent, ileri RAG, evaluation, LangSmith, tracing, maliyet ve güvenlik. |

## Konu başlıkları

- LangChain bileşenleri ve model entegrasyonları
- Prompt templates, LCEL ve runnable composition
- Tools, tool calling ve agents
- Memory ve LangGraph
- MCP ile entegrasyon kavramları
- RAG: chunking, hybrid search, reranking, query transformation, metadata filtering
- Evaluation: retrieval ve answer quality, LLM-as-judge, LangSmith
- Production: observability, tracing, token/maliyet kontrolü, caching, retries ve fallback
- Güvenlik: prompt injection, least privilege, PII koruması ve output validation
